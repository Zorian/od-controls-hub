# OD Controls HQ

Internal hub for OD Controls (Jaydon Goldman and Bafana Khumalo): pipeline, jobs, to-dos, contacts and outreach.

- `data.json` holds every record. Edit this to update the hub.
- `index.html` renders it. Open it locally, or serve the folder.
- Live, editable version: the OD Controls HQ artifact on claude.ai.

Updates are made by Claude on Jaydon's request, so every change is a commit with history.

**Private repo.** Contains client names, phone numbers and money owed. Do not make public.
